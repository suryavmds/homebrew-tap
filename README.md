# suryavmds/tap

A [Homebrew](https://brew.sh) tap for [Strays](https://github.com/suryavmds/strays),
a menu bar app that shows everything running in the background on your Mac
and lets you stop it.

```bash
brew install --cask suryavmds/tap/strays
```

The cask in `Casks/strays.rb` is written by Strays' release workflow each
time a version is tagged. Please report problems in the
[Strays repository](https://github.com/suryavmds/strays/issues).
